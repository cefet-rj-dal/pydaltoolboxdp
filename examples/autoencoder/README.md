# Autoencoders

Deep ++ autoencoders follow the transformation contracts from `pydaltoolbox`.

- [01 — dense encoder](01-autoenc-e.md): learn a compact latent representation.
- [02 — denoising encoder](02-autoenc-denoise-e.md): learn robust latent attributes.
- [03 — convolutional encoder](03-autoenc-conv-e.md): learn local patterns within windows.
- [04 — LSTM encoder](04-autoenc-lstm-e.md): learn temporal representations of windows.
- [05 — stacked encoder](05-autoenc-stacked-e.md): learn hierarchical representations.
- [06 — variational encoder](06-autoenc-variational-e.md): learn latent distribution parameters.
- [07 — adversarial encoder](07-autoenc-adv-e.md): regularize latent codes against a prior.
- [11 — dense encoder-decoder](11-autoenc-ed.md): reconstruct observations and measure error.
- [12 — denoising encoder-decoder](12-autoenc-denoise-ed.md): reconstruct clean observations.
- [13 — convolutional encoder-decoder](13-autoenc-conv-ed.md): reconstruct local window patterns.
- [14 — LSTM encoder-decoder](14-autoenc-lstm-ed.md): reconstruct temporal windows.
- [15 — stacked encoder-decoder](15-autoenc-stacked-ed.md): reconstruct hierarchical bottlenecks.
- [16 — variational encoder-decoder](16-autoenc-variational-ed.md): reconstruct latent samples.
- [17 — adversarial encoder-decoder](17-autoenc-adv-ed.md): reconstruct adversarial codes.
